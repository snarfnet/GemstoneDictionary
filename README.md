# 天然石辞典

写真から天然石の候補を出し、辞書から詳細データを読めるiOSアプリです。

## 主な機能

- ライブカメラ判定
- カメラ撮影と写真選択
- 翡翠とターコイズのサンプル判定。実機カメラがない環境でも結果画面を確認
- 石の候補、名称、透明度、レベル、見かけサイズ、市場価格の目安
- 判定確度の表示。高め/中くらい/低めで、撮り直しや鑑別書確認を案内
- ライブカメラ中の確認中/安定表示
- 暗い、明るすぎる、石が小さいときの撮影アドバイス
- 石と基準物を置く位置がわかるフレーミングガイド
- サイズ推定の信頼度表示。石が小さい、斜め、基準物と高さが違うときに撮り直しの目安を出します
- 直近の候補、レベル、サイズ、基準物、相場を見返せる最近の判定履歴。画像は保存せず、履歴情報だけを端末内に保存
- 候補カードから任意の候補を選んで履歴保存
- 判定結果と履歴をテキストで共有。サイズ推定に使った基準物と信頼度も残ります
- 辞典詳細を鑑別・購入確認メモとして共有
- あいうえお順リスト
- 辞典で色から探すフィルター
- 辞典でランク目安から探すフィルター
- 辞典の該当なし表示と条件リセット
- 気になる石を端末内に保存できるお気に入り
- 検索。例: `た` でターコイズ、タイガーアイなどを表示
- 翡翠を含む150種類以上の詳細データ
- 硬度、比重、屈折率、透明度、処理、見分け方、価格が上がる条件、扱い方
- 辞典詳細の「数値の見方」。硬度、比重、屈折率を購入前確認に使える言葉で説明
- 辞典詳細の「処理・注意ハイライト」。染色、含浸、樹脂、再生品、扱い方を見落としにくく表示
- 鑑別・相場の用語集。A貨翡翠、B貨/C貨、含浸、染色、安定化、再生品、硬度、比重、屈折率、カラット、鑑別書を収録
- 相場タブの購入前チェックリスト。処理、証明、品質、価格をまとめて確認
- 相場タブの150種類以上の相場一覧。各行から詳細へ移動
- 辞典詳細の「迷いやすい石」。翡翠とネフライト、ターコイズとアマゾナイトなどを硬度、比重、処理で比較

## 注意

写真だけで石種や市場価格を断定することはできません。高額品、処理の有無、翡翠のA貨/B貨/C貨判定は、鑑別機関や専門店で確認してください。

## 生成

Xcodeプロジェクトは同梱しています。Macではそのまま開けます。

```bash
open ios/GemstoneDictionary/GemstoneDictionary.xcodeproj
```

`project.yml` から作り直す場合:

```bash
cd ios/GemstoneDictionary
xcodegen generate
open GemstoneDictionary.xcodeproj
```

## 静的チェック

```bash
python scripts/verify_static.py
```

このチェックでは、ライブカメラ、撮影、写真選択、検索、五十音、翡翠、ターコイズ、透明度、レベル、サイズ、市場価格、plist/jsonを確認します。150種類以上の石に硬度、比重、屈折率、透明度、処理、見分け方、価格条件が入っているかも見ます。検索は `た` でターコイズが出ることまで確認します。

GitHub Actionsでは、静的検証とXcodeビルドに加えてUIテストも実行します。UIテストでは、`た` 検索でターコイズ、`jade` 検索で翡翠、相場一覧、翡翠サンプル判定の表示を確認します。

## Macでのビルド確認

```bash
cd ios/GemstoneDictionary
bash scripts/build_mac.sh
```

実機カメラはシミュレータでは確認できません。ライブ判定はiPhone実機で確認してください。

## 判定結果の読み方

写真判定後は、候補名、ランク候補、透明度、サイズ、市場価格に加えて「判定の根拠」を表示します。根拠には色相、彩度、明るさ、画面内サイズが入り、似た色の石や処理品では候補が近く出ることも明記しています。

候補欄には「判定確度」も表示します。最上位候補のスコアと次候補との差を見て、高め、中くらい、低めに分けます。低めのときは撮り直しを案内します。

辞典詳細には「ランク目安」を表示します。S/A/B/Cの見方を石ごとの価格条件や処理とつなげ、写真のレベル表示が鑑定ランクではないことも示します。

辞典詳細には「数値の見方」も表示します。硬度は傷つきにくさ、比重は同じ大きさでの重さ、屈折率は鑑別時の石種確認に使う数値として説明します。

辞典詳細には「処理・注意ハイライト」も表示します。染色、含浸、樹脂、再生品など価格差につながる処理がある場合は、鑑別書で処理欄を確認する案内を出します。

辞典詳細には「似ている石」も表示します。色相差と彩度差を見ながら、硬度、比重、処理、価格条件を比べられます。

辞典詳細には「迷いやすい石」も表示します。収録済みの石から、見た目や流通名で混同しやすいものを固定で出し、硬度、比重、処理を比べられます。

各石の詳細には「購入前チェック」もあります。相場、処理、価格条件、見分け方、鑑別書、返品条件を購入前に確認できます。

各石の詳細には「鑑別・ランク確認メモ」もあります。名称、硬度、比重、屈折率、処理、価格目安をまとめて見られるので、写真判定の候補を実物確認につなげやすくしています。

辞典詳細は「詳細メモを共有」からテキスト共有できます。名称、ランク目安、硬度、比重、屈折率、透明度、相場、価格条件、処理、見分け方をまとめて送れます。

## 相場データ

[MARKET_DATA_NOTES.md](MARKET_DATA_NOTES.md) に、相場更新時の出典、確認条件、更新ルールをまとめています。GIAとInternational Gem Societyの公開資料を参照し、価格は固定額ではなく幅のある目安として扱います。

相場タブには「150種類以上の相場一覧」もあります。石名、ランク目安、市場価格をまとめて見られ、各行から詳細へ移動できます。

相場タブには「買う前に見る項目」もあります。翡翠はA貨/B貨/C貨、ターコイズは無処理/安定化/染色/再生品を分け、鑑別書、返品条件、傷、欠け、重量、産地を見ます。

相場タブには「鑑別・相場の用語集」もあります。処理や物性値の意味をアプリ内で確認し、価格やランク表示を読むときの補助に使えます。
